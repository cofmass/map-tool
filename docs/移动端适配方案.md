# map-tool 移动端适配方案（iOS / Android）

> 2026-11-24 阶段结论。分两条路线：**A. PWA over LAN（已实施）**、**B. Capacitor 打包成原生 App（待实施）**。

## 一、PWA over LAN（已实施 ✅）

手机与电脑同一 Wi-Fi 下即可使用，iOS「添加到主屏幕」后为全屏 App 体验。

### 已落地的改造

| 项 | 文件 | 说明 |
|---|---|---|
| 服务监听 0.0.0.0 | `serve.js` | 启动时自动打印 `http://<本机IP>:8080` 供手机访问；第三个参数可传 `127.0.0.1` 恢复仅本机 |
| PNG 图标 | `icons/` | `icon-192/512.png`（maskable）+ `apple-touch-icon.png`（180，iOS 主屏图标必须 PNG，SVG 不识别）；生成脚本 `icons/make-icons.py`（Pillow） |
| manifest 强化 | `manifest.webmanifest` | `short_name`、`orientation: portrait`、PNG icons |
| iOS meta | `index.html` | `apple-touch-icon`、`apple-mobile-web-app-capable`、`black-translucent` 状态栏 |
| IP 定位兜底 | `app.js` | 非安全上下文（`http://192.168.x.x`）下浏览器 Geolocation 不可用 → 自动改走高德 `/v3/ip` 城市级定位；HTTPS/localhost 下仍用浏览器精确定位 |
| 安全区适配 | `styles.css` | `env(safe-area-inset-*)` 适配刘海/Home 条；输入 16px 防 iOS 聚焦缩放；44px 触控目标；横屏左右布局 |
| SW 版本 | `sw.js` | 缓存升级 `maptool-v4`，壳资源加入 icons |

### 使用方法

```powershell
cd D:\WorkSpace\map-tool
node serve.js 8080          # 控制台会打印手机访问地址
# 手机浏览器打开打印出的 http://192.168.x.x:8080
```

- **iOS**：Safari → 分享 → 添加到主屏幕 → 全屏独立运行。
- **Android**：Chrome → 菜单 → 添加到主屏幕/安装应用。

### 局限（引出路线 B 与内网 HTTPS）

1. `http://192.168.x.x` 属非安全上下文：SW/PWA 安装不可用、定位只有 IP 级精度。解决：
   - mkcert 自签 + 本地域名 + 信任证书（工程量小，效果接近正式）；或
   - 直接走路线 B 打包。
2. 手机端仍依赖电脑开着 serve.js；关机即失效。
3. JS KEY 若以后配了域名白名单，需把访问域名加进白名单。

## 二、Capacitor 打包（路线 B，探究结论）

用 Capacitor 5+ 把现有页面装进原生 WebView，一套代码出 iOS + Android。**现有代码几乎零改动可用**，只需处理两点：

1. **高德 JS SDK 加载**：Capacitor 页面运行在 `capacitor://localhost`（iOS）/ `https://localhost`（Android）自定义 scheme 下，属安全上下文，浏览器定位可用；JS KEY 白名单需加 `localhost`。
2. **Web 服务 KEY 仍走 https restapi.amap.com**，与现在一致，无需代理。

### 实施步骤（实施时展开）

```bash
npm init -y
npm i @capacitor/core @capacitor/cli @capacitor/geolocation
npx cap init "沿途最顺路" "com.example.maptool" --web-dir=www
# 把 index.html/styles.css/app.js/icons 等拷入 www/（或用构建脚本复制）
npx cap add ios
npx cap add android
npx cap sync
npx cap open ios      # 需要 macOS + Xcode
npx cap open android  # 需要 Android Studio
```

- `Info.plist` 需加 `NSLocationWhenInUseUsageDescription`（定位权限描述）。
- Android `AndroidManifest.xml` 需 `ACCESS_FINE_LOCATION` + `INTERNET`。
- 可选 `@capacitor/geolocation` 替换浏览器定位获得系统级 GPS（改动点仅在 `locateCurrent()`）。
- 离线能力：现 sw.js 在 WebView 中同样生效；如需彻底离线，把壳资源直接打进包内（已是本地文件，天然离线）。

### 环境要求

| 平台 | 要求 |
|---|---|
| iOS | 必须 macOS + Xcode（本机 Windows 无法出 ipa，可找 Mac 或云构建服务） |
| Android | Windows 装 Android Studio + JDK 17 即可出 apk |

### 建议

1. 先在 Windows 上出 **Android apk** 验证整链路（成本最低）。
2. iOS 包后续在有 Mac 的环境执行 `npx cap add ios` + Xcode 构建。
3. 分发：内测用 apk 直装 / iOS 用 TestFlight；上架商店需开发者账号且地图类 App 审核对第三方地图 SDK 有额外要求（高德 SDK 有官方 iOS/Android 原生 SDK，上架时也可评估换原生 SDK，但改动量大，不建议现阶段做）。

## 三、后续可选项
