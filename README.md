# 沿途最顺路 · 地图网页工具

按 `docs/设计文档/map-tool/地图网页工具设计方案.md` 实现的纯前端单页应用。

## 功能

- **F1 A→B 导航**：地址输入联想（高德输入提示，按当前定位/已设起点优先就近排序）/ 地图点选（起点、途经点、终点均可） / 当前位置定位并在地图显示蓝点标记 → 路线规划 → 多方案切换。
- **出行方式切换**：🚗 驾车 / 🚲 骑行 / 🚶 步行 / 🚌 公交。驾车使用高德原生多方案与途经点；骑行、步行、公交在含途经点时自动按 A→C1→…→B 拆成多段规划并拼接；公交展示换乘线路、票价与步行距离。偏好保存在 localStorage，切换后已有路线会自动重算。
- **F2 A→C→B 途经点**：支持多个途经点（上限 10，以高德平台实际限制为准），同样支持输入联想与地图点选。
- **F3 关键词沿途最顺路**：沿当前出行方式的路线采样 → POI 关键词搜索 → 粗筛 + 精确绕行计算 → 自动选出最顺路 POI 并展示路线，支持点击候选切换。非驾车模式下「绕行」按当前方式重新规划后的总距离与总时长差值计算；公交按换乘方案拼接估算。
- **明/暗主题**：右上角 🌙/☀️ 或设置弹窗内切换，偏好保存在 localStorage；暗色模式下地图底图同步切换为高德暗色样式。
- **锚点分组筛选**：结果区可按「靠近起点 A」「靠近终点 B」以及每个途经点「靠近 C1…Cn」筛选，每组展示离该锚点最近、绕行最小的 5 个候选；「全部(最顺路)」展示全局 Top 5。
- **途经点 + 顺路组合**：在「路线规划」先规划含途经点 C1…Cn 的路线，再到「沿途搜索」搜关键词。采样走廊基于完整 A→C→B 路线；候选打分用点到段直线距离粗选插入位置，再以完整路线算真实绕行，最终路线为 A→…→P→…→B。候选卡片会显示插入位置（如「A→下一站」），并可按靠近 A/C/B 筛选。当前选中的店在列表中紫色高亮并标注「当前选择」，地图上以紫色光环 + 店名标签突出显示；A/B/C 标记也显示实际地点名称，不再用代号。

## 运行

KEY 已内置（2026-11-24 从已登录的高德控制台读取并实测通过：Web服务 `6c5b817…3892` + Web端JS `07030115…8d7`）。页面右上角 ⚙ 可查看/修改；修改会覆盖默认值并保存在浏览器 localStorage。

Windows 环境用仓库自带 `serve.js`（Node 可用；本机 python 是 Windows Apps 占位符不可用）：

```powershell
cd D:\WorkSpace\map-tool
node serve.js 8080
```

浏览器访问 `http://localhost:8080`。**手机局域网访问**：默认监听 `0.0.0.0`，启动时会打印 `http://<本机IP>:8080`，手机连同一 Wi-Fi 直接打开；iOS Safari「添加到主屏幕」/ Android Chrome「安装应用」可全屏使用。注意：非 HTTPS 下浏览器精确定位不可用，页面自动改用高德 IP 定位（城市级精度）。详见 `docs/移动端适配方案.md`。JS KEY 的域名白名单当前为空（无限制），localhost 可直接使用。页面加载后会自动尝试定位当前位置填入起点（浏览器需授权定位；不授权可手动输入或地图选点）。

## KEY 安全

- KEY 只保存在浏览器 `localStorage`，不上传任何服务器。
- 生产环境务必在高德控制台为 JS KEY 配置域名白名单，Web 服务 KEY 设置 IP / 域名白名单与配额；如配额受限可按设计方案 §7 加轻量代理。

## 配额控制

- 走廊采样点上限 30，默认间隔 2 km、半径 1.5 km（页面可调）。
- 粗筛后最多 20 个候选做精确打分（每组要凑 5 个）；每个候选只发 1 次完整路线 driving 请求，插入位置用点到段直线距离粗选。
- 锚点分组：先按到 A/C/B 的直线距离取最近 10 个，再按绕行排序取 Top 5。
- 所有 REST 请求走全局串行队列 + 420 ms 节流；对高德 QPS 限流（`infocode=10021` / `CUQPS_HAS_EXCEEDED_THE_LIMIT`）做 5 次递增退避重试（2s/4s/…），不消耗业务配额；沿途搜索限流失败会中止整批并给出明确提示。
- 同一会话的基础路线结果可复用，避免重复规划。

## 文件

- `index.html` — 页面结构
- `styles.css` — 样式（桌面 + 移动端）
- `app.js` — 全部逻辑（KEY 管理、REST 封装、四种出行方式、地图绘制、F1/F2/F3）
- `serve.js` — 本地静态服务（Node，无依赖）
- `manifest.webmanifest` / `sw.js` — PWA 支持（iOS 添加到主屏幕；离线壳，接口不缓存）
- `icons/` — PWA 图标（PNG，`make-icons.py` 生成）
- `docs/移动端适配方案.md` — iOS/Android 适配与 Capacitor 打包探究
